<objective>
Resolve the phase's one genuinely open technical question before any dependent code is written: which OpenAI model ID the deployed key can actually reach, and whether that model accepts a custom `temperature`. Install the `openai` SDK (D-06) and freeze the answer into one server-only constants module (D-07).

Purpose: RESEARCH.md Open Questions §1 found that official OpenAI docs and third-party sources actively contradict each other about whether `gpt-4.1-mini` is still callable, and that GPT-5-family reasoning models return a 400 on any non-default `temperature` — which collides head-on with D-07's "fixed low temperature" requirement. Guessing here means the tracer slice fails on its first real call. D-07 is also marked **costly reversibility** (switching to per-agent model config later means touching every call site), so the resolved choice gets a decision checkpoint before dependent plans consume it.

Output: `openai` in package.json, `scripts/probe-openai-model.ts`, recorded live probe output in MODEL-PROBE.md, and `src/lib/server/tryItOutModel.ts` exporting the locked `MODEL` / `TEMPERATURE` / `modelParams`.
</objective>
