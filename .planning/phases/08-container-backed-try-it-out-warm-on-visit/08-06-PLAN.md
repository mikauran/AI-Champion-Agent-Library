<assumption_delta_decision>
Detector fired (pluralization: "fallback"): the phase introduces a second execution backend for a job.
- Primary noun: the container-backed Pi run. `runJob(jobId)` stays the single entry point and now means "run in the session's container".
- Decision: promote. The Phase 7 body is demoted to `runDirectLlmJob`, reachable only from the dispatcher on `engine_unavailable` / `container_start_failed` with PI_FALLBACK_ENABLED. It is not added alongside as a peer mode, and no caller picks a backend.
- Invariant test (added in Task 2): for every RuntimeErrorCode, the dispatcher's choice (fallback vs failed) matches D-14, so a later change cannot quietly turn the fallback into a peer path.
</assumption_delta_decision>
