Pi JSON event facts (RESEARCH R-04, docs/json.md of Pi 1.0.4):
- first record `{"type":"session","version":3,...}`; then agent_start, turn_start, message_start/message_update/message_end, tool_execution_start {toolCallId, toolName, args}, tool_execution_update, tool_execution_end {toolCallId, toolName, result, isError}, turn_end, agent_end {willRetry}, agent_settled; also auto_retry_start {attempt, maxAttempts, errorMessage}, auto_retry_end {success, finalError}
- assistant message_end: `{ type:'message_end', message: { role:'assistant', content: [{type:'text', text}] | string, stopReason, errorMessage? } }`
- tool args: read {path}, write {path, content}, edit {path, oldText, newText}, bash {command}, grep {pattern, path?}, find {pattern, path?}, ls {path?}
