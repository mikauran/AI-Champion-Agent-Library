<objective>
Build the only LLM path a Pi container has: an app-hosted proxy that authenticates a per-lease token, enforces a per-job budget, injects the real key server-side and streams Chat Completions responses through. Let it past the user-auth hook.

Purpose: D-17 (key never enters the container), D-22 (budget part of per-job limits), D-19 (proxy is the single reachable endpoint; token auth separate from user auth).
Output: `llmProxy.ts`, the `/api/llm/v1/chat/completions` route, hooks change, tests.
</objective>
