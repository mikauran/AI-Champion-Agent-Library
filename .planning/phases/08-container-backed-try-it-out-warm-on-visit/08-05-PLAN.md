| T8-05-2 | Tampering (race) | Lease state | high | Concurrent claim and eviction both win, killing a running job or leaking a container | All transitions synchronous (single-threaded CAS); map entry set before first await; race tests |
| T8-05-3 | Information disclosure | Container env / labels | high | Real key or user email placed in the container | Env holds only AIC_LLM_TOKEN; labels hold instance id, slug, timestamp, never sessionKey; test asserts no OPENAI_API_KEY in env |
| T8-05-4 | Spoofing | Session cookie | medium | Guessing another visitor's aic_tryout_sid to share their container | 128-bit random id, httpOnly, sameSite lax, secure per AUTH_COOKIE_SECURE; impact limited to queueing a job in that container |
| T8-05-5 | Elevation of privilege | Token lifetime | high | Token keeps working after the container is gone | revokeLeaseToken in the same synchronous step as evicting/expired/discard; tests assert authenticateBearer fails after eviction and reaping |
| T8-05-6 | Tampering / path traversal | Staging paths | medium | Slug used in in-container paths | AgentIdSchema validation in buildWarmFiles; StagedFile paths are relative and checked by isSafeRelativePath in the runtime |
| T8-05-7 | Repudiation / resource leak | Orphans after restart | medium | Containers survive app restarts and keep consuming resources | Instance-labelled sweep at start-up, SIGTERM cleanup; single replica per engine user documented in plan 08 |
