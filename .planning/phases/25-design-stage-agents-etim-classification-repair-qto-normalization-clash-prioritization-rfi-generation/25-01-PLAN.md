<interfaces>
Facts established while planning (re-verify with grep if a line looks stale):

Job API (src/routes/api/tryitout/jobs):
- POST /api/tryitout/jobs multipart: agentId (kebab slug), task (string, required), optional file (<= 200 KB, becomes input/upload.txt in the job). Returns `{ jobId, status: 'queued' }`. With AUTH_ENABLED=false a client gets an anonymous session cookie; max 5 new anonymous sessions per client per 10 min (PI_RUNNER_ANON_SESSIONS_PER_CLIENT). Send the cookie from the first response on later calls (`set-cookie`), or reuse one cookie jar per harness process.
- SvelteKit CSRF: POSTs need an `Origin` header equal to the app's ORIGIN (compose default http://localhost:3000). Harness sets `Origin: <base-url origin>` and accepts `--origin`.
- GET /api/tryitout/jobs/:id -> `{ status: 'queued'|'running'|'succeeded'|'failed', events: JobEvent[], error: string|null }`.
- GET /api/tryitout/jobs/:id/artifact -> zip of the job's output/ dir (valid when succeeded). The zip is made with fflate (already a dependency: use `unzipSync`/`strFromU8`).

Token usage observation (finding): the LLM proxy (src/lib/server/tryitout/llmProxy.ts) keeps per-job usage in process memory (`JobUsage { jobId, totalTokens, requests, budgetExceeded }`, retrieved with `getJobUsage(jobId)`; `finishedUsage` is retained after the job ends). It is NOT exposed by any route; piRunner only mentions it in the "job token budget exceeded" error. The proxy sums `total_tokens` only (no prompt/completion split). The model is the constant `MODEL` ('gpt-4.1-mini') from src/lib/server/tryItOutModel.ts, imported by tryitout/service.ts for Pi's models.json. Task 1 adds the tiny gated endpoint; do not change the frozen JobUpdate shape or any existing route response.

Container run facts:
- Pi containers reach the app only through `PI_LLM_PROXY_URL` (compose pins http://aic-agent-library:3000/api/llm/v1 on the internal network `aic-pi-internal`, alias `aic-agent-library`). A plain host `npm run dev` cannot be reached from an internal network (no host gateway), so the host-run variant needs an OPEN network + `PI_RUNNER_ALLOW_OPEN_EGRESS=true` + `PI_LLM_PROXY_URL=http://host.containers.internal:<port>/api/llm/v1` (dev only; weaker isolation).
- The app reads the agent's system prompt from the catalog DB (`agents` row, so the agent must be ingested) and SKILL.md from `TRYITOUT_PROMPTS_DIR`. The compose image bakes both in at build time (db/catalog.db opened readonly; data/tryitout-prompts copied). To run NEW agents without rebuilding the 2.68 GB image, a compose override bind-mounts the host's freshly ingested `db/catalog.db` and `data/tryitout-prompts`.
- Images present: localhost/aic-agent-library:latest, localhost/pi-runner:latest. Networks present: aic-pi-internal, aic-agent-library_default. Podman 4.9.3 rootless; socket via `systemctl --user enable --now podman.socket`.
- `scripts/smoke-pi-runner.ts` is the pre-flight check (`npx tsx scripts/smoke-pi-runner.ts`; with the compose app up add `--proxy-host aic-agent-library`).
- Price assumption (gpt-4.1-mini): USD 0.40 per 1M input, 1.60 per 1M output tokens. Because only total tokens are known, the harness prices ALL tokens at the output rate (conservative upper bound): 100000 tokens = 0.16 USD, under the 0.50 cap. Keep prices as named constants with a comment that the OpenAI dashboard is ground truth; allow `--price-per-mtok` override.

    - runJob happy path: submits multipart (agentId, task, file), polls running -> succeeded, downloads and unzips the artifact into --out-dir, reads usage, appends one ledger row, prints a single-line JSON evidence record (jobId, status, model, totalTokens, requests, estCostUsd, outputFiles, firstOutputLines (first 15 lines of the first output file), durationS) and returns 0.
    - runJob failed path (status failed with error): still appends a ledger row (cost from usage if available, else the 0.50 reserve is kept as the row cost, marked `usage-unknown`) and returns 1.
    - Timeout: returns 4 and still writes the reserve row.
    - Usage endpoint 404 (flag off) after a succeeded job: row written with tokens `unknown`, cost = 0.50 reserve, status note `usage-unknown`; the evidence record says `"countable": false` (a run without observed usage cannot count as evidence).
