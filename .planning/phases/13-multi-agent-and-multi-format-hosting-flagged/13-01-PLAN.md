DESIGN DECISION (log as D-033): the memo proposes ALTER TABLE ADD COLUMN on `agents`. Instead use a sidecar table `agent_kinds` (slug PK -> agents.slug ON DELETE CASCADE, kind, framework, topology, members, source_format, extras). Reason: every route/search reader does `db.select().from(agents)` (all columns) and tests create `agents` with hand-written DDL (ingest.test.ts CREATE_TABLE_SQL, route tests with mocked chains); adding columns to the drizzle `agents` table would change generated SQL and returned row shapes with the flag OFF and break old DDL. A sidecar is read only when the flag is on. Revert: drop the table / stop reading it; `agents` is untouched.
</objective>

```ts
import type { AgentRecord } from './types.js'
export const AGENT_KIND_VALUES = ['agent','system','workflow','skill','mcp-server','external-agent'] as const
export type AgentKind = (typeof AGENT_KIND_VALUES)[number]
export type MemberRole = 'manager'|'worker'|'peer'|'step'|'participant'
export interface AgentMember { ref: string; name: string; role: MemberRole; description: string|null; slug: string|null }
export interface KindInfo { kind: AgentKind; framework: string|null; topology: string|null; members: AgentMember[]; sourceFormat: string|null; extras: Record<string, unknown> }
export const DEFAULT_KIND_INFO: KindInfo   // kind 'agent', rest null/[]/{}
export interface SubmissionFile { path: string; text: string }   // path relative, posix separators
export interface DetectResult { format: string; confidence: number }  // 0..1
export type SubmissionStatus = 'ingestible'|'partial'|'missing-from-author'
export interface ParseOutcome { status: SubmissionStatus; format: string; record: AgentRecord|null; kindInfo: KindInfo|null; missingFromAuthor: string[]; unknownFields: string[]; warnings: string[] }
export interface FormatAdapter { id: string; detect(files: SubmissionFile[]): DetectResult|null; parse(files: SubmissionFile[], ctx: { now: string }): ParseOutcome }
export const EXTRAS_MAX_BYTES = 16384
export const MEMBERS_MAX = 50
```
Status meaning: ingestible = record produced and title+summary+category present; partial = record produced but missingFromAuthor non-empty; missing-from-author = no usable record (unknown format or required data absent).
