    - Rules enforced: all tool bodies wrapped in try/except Exception returning `_err`, never `str(e)`, never traceback; tool output keys never include the words timestamp/status/error/path together (only ok/kind/message/hint/results/count/page/page_size/coverage); page size clamped to [1, maxPageSize] with the clamp stated in the tool docstring; when `page * page_size > limits.resultCeiling` return `{"ok": True, "results": [], "warning": "Result ceiling reached ... narrow with <partition filter>"}` (only emitted if resultCeiling set); lookups with 404 or empty return "No <entity> found for <id>"; 200 with zero rows returns `_no_results`.
    - Derived inMemoryFilter tool: signature (key: str, value: str|None = None, <partition/identifier filter>, max_pages: int = 5); it fetches candidate pages itself through the list operation (never takes a caller-supplied product list), filters the nested array locally on keyFields/valueFields, stops at max_pages or maxResponseItems, returns `{"ok": True, "results": [...projected...], "count": n, "coverage": {"pages_scanned": k, "truncated": bool, "note": "..."}}` and an honest message when truncated.
    - Dataset backend: stdlib `csv` reader over the path from env var, loaded fully BEFORE assigning module state (RESEARCH-SYNTHESIS 2.1 lessons), identifiers coerced to str, numeric-aware filters; SQL backend: stdlib `sqlite3` using the path/DSN env var, parameterised queries only, table and column names allow-listed from the model (never interpolated from tool arguments), `PRAGMA query_only = ON`/read-only open. Non-sqlite SQL DSNs are out of scope: noted in the report as an assumption.
    - Docstrings: every tool has a task-oriented one-line description plus Args; description text from the model is escaped (no triple quotes, no backslash sequences, control chars stripped) so spec text can never break out of the string.
    - requirements.ts: emits `requirements.txt` with `fastmcp>=3.4,<4` and `httpx>=0.27` (http backend only); pytest listed in a separate dev line. Version pin flagged UNVERIFIED in the report assumptions (RESEARCH-SYNTHESIS section 6 Q4).
