    **Step 1: Create `scripts/ingest.ts`**

    Imports:
    - `readdir`, `readFile`, `mkdir` from `'node:fs/promises'`
    - `join`, `dirname` from `'node:path'`
    - `Database` from `'better-sqlite3'`
    - `drizzle` from `'drizzle-orm/better-sqlite3'`
    - `sql` from `'drizzle-orm'`
    - `parse as parseYaml` from `'yaml'`
    - `agents` from `'../drizzle/schema.js'`
    - `detectFormat`, `normalize` from `'../src/lib/spec/index.js'`
    - type `AgentRecord` from `'../src/lib/spec/types.js'`

    Define constants:
    - `DATA_DIR` = `process.env.INGEST_DATA_DIR ?? './data/agents'`
    - `DB_PATH` = `process.env.INGEST_DB_PATH ?? './db/catalog.db'`

    Define helper `flattenRecord(record: AgentRecord): NewAgentRow`:
    - Maps `record.llm.name` to `llmName`
    - Maps `record.llm.temperature` to `llmTemperature`
    - Maps `record.llm.maxTokens` to `llmMaxTokens`
    - Maps `record.llm.topP` to `llmTopP`
    - Serializes `record.toolNames` with `JSON.stringify()`
    - Serializes `record.tags` with `JSON.stringify()`
    - Passes through all other fields directly
    - Sets `lastIngestedAt` to `new Date().toISOString()`

    Define `async function ingest(dataDir: string, dbPath: string)`:
    - Create db directory: `await mkdir(dirname(dbPath), { recursive: true })`
    - Open SQLite: `const sqlite = new Database(dbPath)`
    - Enable WAL mode: `sqlite.pragma('journal_mode = WAL')`
    - Create Drizzle instance: `const db = drizzle(sqlite)`
    - Read files: `const files = (await readdir(dataDir)).filter(f => f.endsWith('.yaml') || f.endsWith('.yml') || f.endsWith('.json'))`
    - Initialize counters: `let succeeded = 0; let failed = 0`
    - For each file:
      - Read content: `const content = await readFile(join(dataDir, file), 'utf-8')`
      - Try/catch block:
        - Parse: `const raw = parseYaml(content)`
        - Detect format: `const formatId = detectFormat(raw)`
        - Normalize: `const record = normalize(formatId, raw)`
        - Flatten: `const row = flattenRecord(record)`
        - Upsert using `db.insert(agents).values(row).onConflictDoUpdate({ target: agents.slug, set: { title: sql\`excluded.title\`, summary: sql\`excluded.summary\`, systemPrompt: sql\`excluded.system_prompt\`, llmName: sql\`excluded.llm_name\`, llmTemperature: sql\`excluded.llm_temperature\`, llmMaxTokens: sql\`excluded.llm_max_tokens\`, llmTopP: sql\`excluded.llm_top_p\`, toolNames: sql\`excluded.tool_names\`, requiresHumanApproval: sql\`excluded.requires_human_approval\`, category: sql\`excluded.category\`, githubUrl: sql\`excluded.github_url\`, maturityStatus: sql\`excluded.maturity_status\`, tags: sql\`excluded.tags\`, specId: sql\`excluded.spec_id\`, lastIngestedAt: sql\`excluded.last_ingested_at\` } })`
        - Increment `succeeded`
      - Catch: `console.error(\`[SKIP] \${file}: \${(err as Error).message}\`); failed++`
    - Log: `console.log(\`Ingestion complete: \${succeeded} succeeded, \${failed} failed\`)`
    - Close: `sqlite.close()`
    - Return `{ succeeded, failed }`

    Export the `ingest` function for testing: `export { ingest }`.

    Add main guard at bottom:
    ```typescript
    const isMain = import.meta.url === `file://${process.argv[1]}`
    if (isMain) {
      ingest(DATA_DIR, DB_PATH).catch(err => { console.error(err); process.exit(1) })
    }
    ```
