    - Description: `summary: string`, `systemPrompt: string`
    - LLM: `llm: AgentLlm`
    - Capabilities: `toolNames: string[]`, `requiresHumanApproval: boolean`
    - Catalog metadata: `category: string | null`, `githubUrl: string | null`, `maturityStatus: 'production' | 'beta' | 'experimental'`, `tags: string[]`

    Export both interfaces. Add a `slugify` helper function: lowercase, replace non-alphanumeric with hyphens, collapse multiple hyphens, trim leading/trailing hyphens. Export `slugify`.

    **Step 3: Create `src/lib/spec/oracle-agentspec.ts`**

    Import `z` from `'zod'` and `AgentRecord`, `slugify` from `'./types.js'`.

    Define `OracleAgentSpecSchema` using Zod 4 syntax:
    - `component_type: z.literal('Agent')`
    - `id: z.string().optional()`
    - `name: z.string().min(1)`
    - `description: z.string().optional()`
    - `metadata: z.record(z.unknown()).optional()`
    - `system_prompt: z.string().min(1)`
    - `llm_config: z.object({ name: z.string().min(1), description: z.string().optional(), metadata: z.record(z.unknown()).optional(), default_generation_parameters: z.object({ max_tokens: z.number().int().positive().optional(), temperature: z.number().min(0).max(2).optional(), top_p: z.number().min(0).max(1).optional() }).optional() })`
    - `tools: z.array(z.object({ name: z.string() }).passthrough()).optional()`
    - `toolboxes: z.array(z.unknown()).optional()`
    - `inputs: z.array(z.unknown()).optional()`
    - `outputs: z.array(z.unknown()).optional()`
    - `human_in_the_loop: z.boolean().optional()`
    - `min_agentspec_version: z.string().optional()`
    - `max_agentspec_version: z.string().optional()`

    Export `OracleAgentSpecSchema` and type `OracleAgentSpec = z.infer<typeof OracleAgentSpecSchema>`.

    Create helper functions:
    - `extractMeta(metadata: Record<string, unknown> | undefined, key: string): string | null` — returns `metadata?.[key]` as string or null
    - `extractMetaArray(metadata: Record<string, unknown> | undefined, key: string): string[]` — returns metadata key as string[] or empty array

    Create and export `fromOracleAgentSpec(raw: OracleAgentSpec): AgentRecord`:
    - `slug: slugify(raw.name)`
    - `title: raw.name`
    - `specId: raw.id ?? null`
    - `summary: raw.description ?? ''`
    - `systemPrompt: raw.system_prompt`
    - `llm: { name: raw.llm_config.name, temperature: raw.llm_config.default_generation_parameters?.temperature ?? null, maxTokens: raw.llm_config.default_generation_parameters?.max_tokens ?? null, topP: raw.llm_config.default_generation_parameters?.top_p ?? null }`
    - `toolNames: (raw.tools ?? []).map(t => t.name)`
    - `requiresHumanApproval: raw.human_in_the_loop ?? false`
    - `category: extractMeta(raw.metadata, 'category')`
    - `githubUrl: extractMeta(raw.metadata, 'github_url')`
    - `maturityStatus`: cast `extractMeta(raw.metadata, 'maturity')` to union type with fallback `'experimental'`
    - `tags: extractMetaArray(raw.metadata, 'tags')`
    - `lastIngestedAt: new Date().toISOString()`

    **Step 4: Create `src/lib/spec/index.ts`**

    Import `AgentRecord` from `'./types.js'`, `fromOracleAgentSpec` and `OracleAgentSpecSchema` from `'./oracle-agentspec.js'`.

    Define `type FormatId = 'oracle-agentspec'`.

    Export `detectFormat(raw: unknown): FormatId` — checks `typeof raw === 'object' && raw !== null && (raw as Record<string, unknown>).component_type === 'Agent'`, returns `'oracle-agentspec'`. Otherwise throws `Error('Unrecognized agent spec format: no component_type === "Agent" found')`.

    Export `normalize(formatId: FormatId, raw: unknown): AgentRecord` — if formatId is `'oracle-agentspec'`, calls `OracleAgentSpecSchema.safeParse(raw)`, throws on failure with Zod error message, returns `fromOracleAgentSpec(result.data)` on success. For unknown formatId, throws.

    Re-export `AgentRecord` and `AgentLlm` from `'./types.js'` for consumer convenience.
